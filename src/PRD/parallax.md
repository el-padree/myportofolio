# Parallax Progress Notes

## Yang sudah dilakukan

- Memeriksa struktur project portfolio dan komponen utama yang terlibat dalam halaman landing.
- Meninjau komponen [src/sections/Parallax.jsx](../sections/Parallax.jsx) dan memastikan isinya sesuai dengan versi Parallax yang sebelumnya dibuat.
- Mengembalikan implementasi Parallax dengan animasi GSAP dan scroll-trigger yang bertujuan memberi efek slide heading yang dinamis.
- Menyesuaikan kebutuhan dependency untuk animasi, termasuk instalasi GSAP agar komponen Parallax dapat berjalan dengan benar.
- Memeriksa apakah ada issue terkait stale test dan default app template yang masih menyisakan teks "learn react".
- Menyelaraskan pemahaman bahwa project ini adalah portfolio personal, bukan template default React.
- Mengonfirmasi status project melalui pemeriksaan file dan terminal terakhir (install GSAP dan test berhasil dijalankan dengan exit code 0).

## Fokus utama Parallax

- Menampilkan serangkaian slide headline dengan kombinasi label, accent, dan dekorasi visual.
- Menggunakan GSAP untuk animasi masuk, keluar, dan background motion saat scroll.
- Memberikan efek scroll storytelling yang lebih dinamis dan modern untuk bagian landing page.
- Menggabungkan visual grid/background serta elemen floating shape agar terlihat lebih hidup.

## Hasil yang sudah dicapai

- Komponen Parallax berhasil dikembalikan dan tersimpan pada file yang tepat.
- Project memiliki struktur yang lebih konsisten dengan desain portfolio yang sedang dikembangkan.
- Setup dependency untuk animasi siap dipakai tanpa error dasar pada project.

## Catatan penting

- Jika nanti ada perubahan desain, komponen Parallax bisa disesuaikan ulang tanpa mengubah struktur utama halaman.
- Untuk maintenance selanjutnya, tetap prioritaskan pengujian real behavior agar tidak ada artifact default dari template React yang tertinggal.
